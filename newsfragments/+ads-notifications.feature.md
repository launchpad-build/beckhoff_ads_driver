Add an ADS device-notification read path so PLC state is pushed to a background callback and cached, instead of issuing a synchronous SUM read every control cycle. This removes the network round-trip from `read()`, decoupling the control-loop rate from network latency. The synchronous SUM read stays the default; set `read_mode=notification` on the `<hardware>` tag to switch to the push path. Per-state-interface tuning is available via the `notify_mode` (onchange/cyclic), `notify_cycle_ms`, and `notify_max_delay_ms` URDF parameters. The write path is unchanged.
