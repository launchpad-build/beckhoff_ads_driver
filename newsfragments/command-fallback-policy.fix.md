Command interfaces now choose what is sent on a cycle where no controller wrote one, through a `command_fallback` interface parameter of `hold_last`, `mirror_state` or `zero`. The mirror-state path never worked: command interfaces were linked to their state interfaces after the write buffers had already resolved the fallbacks out of that link, so the map was always empty and every interface silently held its last value. Linking now happens first, the lookup is guarded against a missing pair, and `hold_last` stays the default so existing behaviour is unchanged. `zero` suits a velocity command, where holding the last value keeps a dead controller's feed-forward alive. Fallback activations are counted. (command-fallback-policy)
