The outage handling now suits a motion stream. The grace window default drops from 1000 ms to 100 ms, matching the PLC's own ROS link watchdog, so ROS surfaces a dead link no later than the machine stops; comms_outage_grace_ms still overrides it. A hard fault now latches by default instead of self-clearing on the next good round-trip, so a recovered link cannot silently resume the stream with a position step of up to velocity times outage; the component faults, restarts deliberately and reseeds. outage_behaviour=resume restores the old self-clearing behaviour for hold-last telemetry and GPIO stacks. read() also stops hiding staleness: once the published sample is older than read_staleness_timeout_ms, 100 ms by default and raised to three poll periods under paced reading, read() returns an error instead of frozen feedback that reports healthy; 0 disables the check.
