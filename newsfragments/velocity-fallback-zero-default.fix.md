Joint velocity command interfaces now default to a zero command fallback. hold_last was the default for every command interface, so a controller unloading mid-move left its last velocity target being re-sent as a live feed-forward every cycle. A joint velocity interface with no explicit command_fallback now falls back to zero and logs that choice at configure; declaring hold_last or mirror_state overrides it. Position, gpio and every other interface keep hold_last as before. (velocity-fallback-zero-default)
