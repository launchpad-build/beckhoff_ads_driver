A PLC symbol the runtime does not have no longer takes the whole stack down. An unresolved handle used to stay in the sum buffers with a zero handle, so every round trip returned a per-item error, `read()` faulted the component on the first cycle and the controller manager cascade-deactivated every controller. Interfaces can now declare `optional="true"`, which drops the symbol from the buffers with a warning and leaves those interfaces at their initial value; a required symbol that is missing fails `on_configure` instead, before anything is running. This is what lets a bringup that reads new diagnostics be deployed against a PLC that has not been flashed yet. (optional-plc-symbols)
