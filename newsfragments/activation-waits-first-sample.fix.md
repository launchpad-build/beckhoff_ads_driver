on_activate no longer returns before the first PLC sample lands. It returned immediately, so early read() calls published NaN into any controller that samples state on activation. Activation now waits, bounded by activation_first_sample_timeout_ms with a 1000 ms default, for the first good sample; it fails cleanly on timeout or on a link fault during the wait, and 0 restores the old return-immediately behaviour.
