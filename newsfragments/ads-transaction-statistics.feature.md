The interface now publishes its ADS transaction behaviour through the controller manager's introspection topic: read and write round-trip times, transaction counts, coalesced writes, read and write failures, command-fallback activations and the heartbeat value. Coalescing a write is the intended policy, since only the newest setpoints matter, but the rate it happens at is how you tell whether the link keeps up with the control loop, and it was invisible. The reader also yields the shared AMS port to a waiting setpoint, because a read started first holds the port for a whole round trip and reads tolerate being a cycle late where setpoints do not.
