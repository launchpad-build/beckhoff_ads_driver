The I/O threads now run with real-time scheduling by default. Both were plain std::thread under SCHED_OTHER, so any wake delay after the write notify let a newer buffer overwrite the pending one, a coalesced and therefore lost setpoint. Both threads default to SCHED_FIFO at priority 50 and can be tuned or disabled through the io_thread_scheduling_policy (fifo, rr, other or inherit), io_thread_priority and io_thread_cpu_affinity hardware parameters. When the process lacks the real-time capability the interface warns, names the fix and carries on with normal scheduling. (io-thread-real-time-scheduling)
