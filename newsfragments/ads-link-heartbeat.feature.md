An optional `heartbeat_plc_symbol` hardware parameter makes the interface advance a UDINT counter on the PLC on every write. A PLC-side watchdog can then tell a live control stack from one that died mid-move, and hold the machine instead of driving to the last target it received. The interface owns the counter rather than a controller, so it also stops when the controller manager stalls or the writer thread wedges. Absent parameter leaves the behaviour unchanged. Watch the counter for movement, never for a step of one: the writer coalesces, so it jumps. (ads-link-heartbeat)
