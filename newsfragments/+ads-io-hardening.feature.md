Harden the notification and threaded I/O paths. In `read_mode=notification`, `read()` now reports an error when a cyclic notification that was updating goes stale past the new `notify_timeout_ms`. A symbol still awaiting its first sample at startup stays exempt, as do on-change notifications, so activation still succeeds. The notification context registry reuses slots across reconfigure cycles instead of leaking one per configure, and the dispatcher callback reads a lock-free snapshot instead of taking a mutex. The polling reader thread backs off after a failed transaction and takes an optional `read_poll_period_ms` to cap PLC load. The writer hands buffers over by swap instead of copy. Notify cycle and delay values get a range check before conversion.
