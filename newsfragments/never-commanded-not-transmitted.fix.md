The PLC no longer receives values nothing commanded. The sum-write buffer is zero-filled when built, the packing loop skips fields no controller has written, and the whole buffer was transmitted anyway, so from activation until the first command every write forced every symbol to zero, which for a position setpoint is a commanded move to the origin. A write item is now transmitted only once every one of its fields holds a provided value: a controller command, an applied fallback, or a declared initial_value, which the framework applies to the command handle at export and the buffer is seeded from at configure. Items still waiting for a first value are left out of the transmitted request entirely. Unmapped elements of a partially mapped PLC array still transmit zero once their item is included, as before.
