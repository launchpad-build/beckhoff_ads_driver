A per-item read failure can no longer freeze a joint's feedback forever while the component reports healthy. Only all-items-failed tripped the outage path; a single invalidated handle held its state interface at the last value indefinitely, which is deliberate for telemetry and wrong for a joint position. State interfaces can now be critical: a critical item whose per-item read keeps failing beyond the grace window hard-faults the component. Joint position and velocity interfaces are critical by default; gpio, sensor and other joint interfaces are not. A critical interface parameter of true or false overrides the default either way, and the state_interface_PLC xacro macro passes it through. (critical-state-items)
