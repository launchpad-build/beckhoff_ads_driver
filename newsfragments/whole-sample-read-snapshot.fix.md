read() can no longer publish a torn snapshot. The reader thread stored decoded values one atomic slot at a time while the control loop read them, so one joint's position could come from a newer sample than another's, or than its own velocity, skewing a pair by up to a read cycle. The reader now publishes each whole decoded sample through a wait-free triple buffer, so every state interface in a control cycle comes from the same SUM read. Each sample carries a steady-clock stamp and the new ads_read_sample_age_ms introspection value exposes how old the published state is. (whole-sample-read-snapshot)
